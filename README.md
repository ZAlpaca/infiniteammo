# infiniteammo
Позволяет стрелять БЕСКОНЕЧНО!!!!!!  
Команды для управления через RA:  
ia - вкл/выкл  
ia onlyammo - потраченные патроны возвращаются в инвентарь, в момент перезарядки все коробки с патронами пропадают с карты.  
ia autoreload - патроны в магазине впринципе не кончаются и оружие стреляет бесконечно, каждый выстрел добавляется по 1 патрону в магазин  
ia off - выключить)  
# оптимизация
очищает только коробки  
ItemType.Ammo9x19 or ItemType.Ammo762x39 or ItemType.Ammo556x45 or ItemType.Ammo12gauge;  
так что если нужно прям все-все чистить или наоборот удалить чистилку - делайте это сами в EventHandlers.cs изменив ClearAmmoPickups();
